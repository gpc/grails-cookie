        • jakarta.servlet.http.Cookie setCookie(java.lang.String name, java.lang.String value, java.lang.Integer maxAge, java.lang.String path, java.lang.String domain, java.lang.Boolean secure, java.lang.Boolean httpOnly)

          Sets the cookie with name to value, with age in seconds

          Parameters:
          name - Cookie name. Can't be blank or null and is case-sensitive
          value - Cookie value.
          maxAge - Age to store cookie in seconds; if negative, means the cookie is not stored; if zero, deletes the cookie.
          path - A path to which the client should return the cookie.
          domain - Domain name by RFC 6265.
          secure - Indicates to the browser whether the cookie should only be sent using a secure protocol.
          httpOnly - Denies accessing to JavaScript's document.cookie.
