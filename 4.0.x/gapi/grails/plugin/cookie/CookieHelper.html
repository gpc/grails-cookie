        • int getDefaultCookieAge(java.lang.Integer maxAge)

          Default expiration age for cookie in seconds. Max-Age attribute. If -1 the cookie will not be stored and is removed after browser close. If null or unset, will use 30 days (2592000 seconds). Cannot be 0 since that means delete the cookie.

        • boolean getDefaultCookieHttpOnly(java.lang.Boolean httpOnly)

          Default HTTP Only flag — denies access from JavaScript's document.cookie. Defaults to true.

        • java.lang.String getDefaultCookiePath(java.lang.String path)

          Default path for cookie selection strategy. 'context' - web app context path (default) 'root' - root of server, i.e. '/' 'current' - current directory, i.e. controller name

        • boolean getDefaultCookieSecure(java.lang.Boolean secure)
